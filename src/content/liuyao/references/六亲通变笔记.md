## 一、什么是六亲通变

### 1.1 标准六亲

以卦宫五行为中心，根据五行生克确定六亲：

| 六亲 | 关系 | 说明 |
|------|------|------|
| 父母 | 生我者 | 卦宫五行生某爻五行 |
| 官鬼 | 克我者 | 某爻五行克卦宫五行 |
| 妻财 | 我克者 | 卦宫五行克某爻五行 |
| 子孙 | 我生者 | 某爻五行生卦宫五行 |
| 兄弟 | 比和者 | 某爻五行与卦宫五行相同 |

### 1.2 六亲通变

> **核心思想**：以任意爻为中心，重新按生克关系定义六亲

六亲通变源于五行生克与卦爻的灵活对应。其核心在于：六亲并非固定标签，而是随"用神"转换而动态变化的角色系统。

**关键公式**：
```
克我者 → 官鬼
我克者 → 妻财
生我者 → 父母
我生者 → 子孙
与我比和者 → 兄弟
```

## 二、通变原理详解

### 2.1 通变规则

以任意爻为中心爻，按以下规则重新定义六亲：

| 关系 | 通变六亲 | 说明 |
|------|----------|------|
| 中心爻克目标爻 | 妻财 | 我克者为妻财 |
| 目标爻克中心爻 | 官鬼 | 克我者为官鬼 |
| 中心爻生目标爻 | 子孙 | 我生者为子孙 |
| 目标爻生中心爻 | 父母 | 生我者为父母 |
| 中心爻与目标爻比和 | 兄弟 | 五行相同 |

### 2.2 通变五步

```
1. 确定中心爻（如：妻财爻午火）
2. 提取中心爻五行（如：午火 → 火）
3. 提取目标爻五行（如：申金 → 金）
4. 按规则判断关系（火克金 → 妻财）
5. 确定通变六亲
```

### 4.4 实战分析

| 通变结果 | 象意 | 实战意义 |
|----------|------|----------|
| 子水变**官鬼** | 克中心者 | 竞争对手、压力 |
| 寅木变**父母** | 生中心者 | 客源、吸引客流的因素 |
| 辰戌土变**子孙** | 中心生者 | 员工、下属、口碑 |
| 午火变**兄弟** | 比和者 | 盈利本身 |
| 申金变**妻财** | 中心克者 | 支出、成本 |

**核心洞察**：
- 子水变官鬼 → 竞争对手在克客流（竞争激烈）
- 寅木变父母 → 木生火，客流来源是吸引客人的关键
- 申金变妻财 → 食材成本是盈利的直接消耗

## 八、六亲通变核心要点

### 8.1 原理总结

```
标准六亲：以卦宫五行为中心
通变六亲：以任意爻五行为中心
关系逆转：重新按生克定义亲疏
```

### 8.2 规则总结

| 中心爻与目标爻关系 | 通变六亲 |
|-------------------|----------|
| 中心克目标 | 妻财 |
| 目标克中心 | 官鬼 |
| 中心生目标 | 子孙 |
| 目标生中心 | 父母 |
| 中心与目标比和 | 兄弟 |

### 8.3 实战价值

1. **信息扩增**：同一卦通过不同中心获得多层次信息
2. **立体分析**：从不同角度验证判断
3. **精准定位**：针对具体问题选择合适中心

### 8.4 注意事项

- 通变是高层次技法，需先掌握标准六亲
- 选择中心爻要根据占事确定
- 通变结果需结合旺衰、动变综合判断
