# 六爻

六爻，又称纳甲筮法，是中国传统预测术中最为普及的分支之一。以铜钱三枚起卦，配以六亲、六神、六兽，综合五行生克冲合，论断人事吉凶。

## 学习路径（8 步里程碑）

| # | 里程碑 | 核心能力 | 过关标准 |
|---|--------|----------|----------|
| ① | **装卦** | 完整排出月日干支、世应、六亲、六神、动变 | 5分钟完成陌生卦象 |
| ② | **世应定位** | 世爻应爻定义、八宫卦世应歌诀 | 准确标注世应五行关系 |
| ③ | **六亲配置** | 五类六亲生克关系与象意 | 给日干推导任意地支六亲属性 |
| ④ | **六神配置** | 日干配六神歌诀、六亲×六神联合分析 | 绘制六神速查表并联合断卦 |
| ⑤ | **旺衰判断** | 月令定旺衰、日辰加持、动变回头生克 | 综合判断用神最终旺衰 |
| ⑥ | **用神选取** | 六亲取用速查表、用神不现/两现处理 | 30秒内确定陌生占事用神 |
| ⑦ | **动变分析** | 独发多动、化进化退、伏神飞神 | 分析动变链条判断发展方向 |
| ⑧ | **独立断卦** | 全流程综合断卦 + 推应期 | 独立完成真实占问全流程 |

→ [查看完整学习路径图 →](/xiuanyan-academy/liuyao/路径图)

## 推荐学习阶段

```
第一阶段（1-2周）：①装卦 → ②世应定位 → ③六亲配置
第二阶段（2-3周）：④六神配置 → ⑤旺衰判断
第三阶段（3-4周）：⑥用神选取 → ⑦动变分析
第四阶段（持续）：  ⑧独立断卦 + 大量实战练习
```
