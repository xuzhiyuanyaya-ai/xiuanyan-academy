# 八字

八字，又称四柱命理，以出生年月日时配以天干地支，共得八个字，故名八字。通过分析日主旺衰、用神喜忌、大运流年，论断一生运势。

## 学习路径

1. **基础理论**：阴阳五行、天干地支、刑冲合害
2. **排盘技能**：起大运、算流年
3. **旺衰判断**：得令、失令党众
4. **用神选取**：扶抑、调候、病药、通关
5. **格局判断**：普通格局与特殊格局
6. **大运流年**：动态分析人生起伏
